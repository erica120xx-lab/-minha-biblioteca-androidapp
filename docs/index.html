Próxima etapa: executar os APKs

Esta primeira versão é a biblioteca. Um navegador Android não executa arquivos APK diretamente. Para jogar sem instalar no celular, precisaremos conectar cada jogo a um servidor/emulador remoto e transmitir a imagem e os comandos. Isso ainda não está incluído nesta versão.
